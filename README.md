# Web for All — Recherche de stages et suivi des candidatures

**Projet de développement web · CESI · Deuxième année**

## Objectif

Concevoir une application web qui centralise les offres de stage et facilite le suivi des candidatures des étudiants. Le projet relie les offres, les entreprises et les utilisateurs dans une interface organisée selon leur rôle.

## Fonctionnalités

- Consulter les offres et effectuer une recherche par titre ou par entreprise.
- Gérer les offres : description, compétences attendues, rémunération et dates.
- Candidater à une offre avec une lettre de motivation et un CV.
- Consulter ses candidatures et associer un pilote pédagogique à son suivi.
- Ajouter ou retirer une offre de sa liste de favoris.
- Distinguer les accès des étudiants, des pilotes pédagogiques et des administrateurs.

## Technologies et architecture

L'application utilise **PHP, HTML, CSS, JavaScript et SQL**, avec **PDO** pour les échanges avec la base de données. Le code suit une organisation **modèle–vue–contrôleur (MVC)** : les modèles portent les opérations sur les données, les contrôleurs traitent les actions et les vues composent les pages.

Les données relient notamment les entreprises, les offres, les compétences et les candidatures. Composer gère les dépendances et PHPUnit est déclaré comme outil de test.

## Finalité du projet

Construire un parcours complet, de la recherche d'une offre au dépôt d'une candidature, et mettre en pratique la conception d'une application web connectée à une base de données : formulaires, sessions, rôles et manipulation de données relationnelles.
